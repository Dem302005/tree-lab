# Дерева (Tree)

Розв'язання 9 задач на бінарні дерева. Мова: Python 3.8+, без зовнішніх залежностей.

| № | Задача | Файл | Ідея | Час |
|---|--------|------|------|-----|
| 1 | Те саме дерево | `trees/task1_same_tree.py` | порівняння кореня та піддерев | O(n) |
| 2 | Симетричне дерево | `trees/task2_symmetric_tree.py` | стек дзеркальних пар вузлів | O(n) |
| 3 | Інвертувати дерево | `trees/task3_invert_tree.py` | обмін лівого й правого нащадка | O(n) |
| 4 | K-й найменший у BST | `trees/task4_kth_smallest.py` | ітеративний inorder-обхід | O(h+k) |
| 5 | Серіалізація / десеріалізація | `trees/task5_codec.py` | BFS, `#` = порожній вузол | O(n) |
| 6 | Максимальна сума шляху | `trees/task6_max_path_sum.py` | post-order, внесок гілок | O(n) |
| 7 | Камери бінарного дерева | `trees/task7_binary_tree_cameras.py` | жадібний алгоритм зі станами 0/1/2 | O(n) |
| 8 | Вертикальний обхід | `trees/task8_vertical_traversal.py` | трійки (стовпець, рядок, значення) + сортування | O(n log n) |
| 9 | Відновлення з preorder | `trees/task9_recover_from_preorder.py` | стек поточного шляху за глибиною | O(n) |

`trees/tree_node.py` містить `TreeNode`, `build_tree(list)` та `to_list(root)` для
запису дерев у форматі LeetCode (`None` = відсутній вузол).

## Запуск тестів

```bash
python -m unittest -v
```

Тести покривають усі приклади з умови та додаткові граничні випадки
(порожнє дерево, один вузол, від'ємні значення, вироджені дерева на 10 000 і 30 000 вузлів).
